# Statistical Modelling of Factors Affecting Student Academic Performance

## Overview

This benchmark asset is an Overleaf/LaTeX research-document project focused on statistical modelling of factors associated with student academic performance.

The project uses a 60-observation synthetic student-performance dataset and develops a multiple linear regression model to examine the relationship between academic performance and selected explanatory variables.



## Task

The completed project should contain:

- Introduction and research objectives/questions.
- Literature review with integrated references.
- Methodology describing the study variables and regression framework.
- Results containing descriptive statistics, correlation analysis, regression modelling, model validation, and interpretation.
- Conclusion containing findings, recommendations, and limitations.
- A successfully compiled final research document.

## Milestones

### Milestone 1 — Project Foundation

Established the initial LaTeX research project structure, title page, introduction, bibliography, and basic document configuration.



### Milestone 2 — Literature Review & Citation Integration

Developed the literature review and integrated the relevant references into the research document.



### Milestone 3 — Methodology & Regression Framework

Developed the methodology chapter, defined the study variables, and established the multiple linear regression framework.



### Milestone 4 — Statistical Model, Results & Validation

Completed the results stage, including descriptive statistics, correlation analysis, regression modelling, model performance measures, a worked prediction, residual-based validation, and interpretation.



### Milestone 5 — Conclusion & Complete Research Document

Completed the conclusion chapter with findings, recommendations, and limitations, and connected it to the main LaTeX document.



## Final Expected State

The final asset should:

- Open as an editable Overleaf/LaTeX project.

- Use the supplied synthetic student-performance dataset.

- Preserve the milestone history and checkpoint structure.



## Dataset Note

The student-performance dataset is synthetic and is included for demonstrative benchmark purposes. The resulting model should be interpreted as an illustration of the statistical modelling process rather than evidence about a real student population.
